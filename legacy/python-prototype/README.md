# Архив: ранний Python-прототип

Этот каталог содержит ранний FastAPI/React-прототип TaskFlow.

Он сохранён только для истории разработки и **не является канонической сдачей**.

Каноническая реализация находится в `../kanban/`:

- Go + PostgreSQL;
- React + Vite + TypeScript;
- тесты backend и frontend;
- Docker и документация.

Не запускайте этот прототип как production-решение и не дублируйте его API в итоговом продукте.
